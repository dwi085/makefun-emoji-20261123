# One Emoji, One Smile

Entry for the [make.fun bounty "One Emoji, One Smile"](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f).

The program (`main.ts`, Node 22) writes exactly one emoji to `/output/entry.txt` — the hugging face 🤗, the single emoji most likely to make a stranger smile: warm and friendly at first glance, universal across any age or background, a chosen gesture rather than the default smiley, and right for a stranger. Deterministic: two runs produce byte-identical output.
